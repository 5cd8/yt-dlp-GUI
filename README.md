## 既知の制限

### Cookieファイルの同時使用

yt-dlpは、`--cookies` で渡したファイルを、終了のたびに書き戻します。チャットリプレイを取得するキュー項目（ライブ以外のYouTube）では、動画取得とチャット取得の2つのyt-dlpが、同じCookieファイルを同時に使うことがあります。チャンネル事前投入をキュー処理と並行して動かしたときも同じです。

ほぼ同時に終わった場合、片方が書き戻したCookieの更新を、もう片方が上書きして失う可能性があります。ファイルが壊れる可能性もゼロとは言えません（推測。実機では再現しておらず、Cookieファイルが壊れたことはありません）。失われた更新は、次の実行で取り直されるのが普通です。

ログインが必要な動画で認証エラーが続くときは、Cookieファイルを書き出し直してください。詳しくは [docs/adr/0008](docs/adr/0008-chat-fetch-starts-during-postprocessing.md) を参照してください。
