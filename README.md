# yt-dlp-GUI
yt-dlpのGUIラッパー。URLをキューに積み、動画または音声を順にダウンロードするWindowsデスクトップアプリです。再生や表示の機能は持たない、純粋なダウンローダーです。

## 機能

### ダウンロード
- URLをキューに追加し、順に動画または音声をダウンロードします。キューの項目は、ダウンロード待ち・ダウンロード中・ダウンロード完了・キャンセル・失敗のステータスで管理します。
- 動画は、追加時に表示されるフォーマット一覧から選びます。音声のみの抽出（mp3・m4a・opus・wav）にも対応します。
- プレイリストのURLは、動画ごとにキューへ追加します。「プレイリストに既定フォーマットを適用」で、フォーマットの選択を省けます。
- ログインが必要な動画向けに、Cookieファイルを指定できます（既定のCookieは設定で保存）。
- 失敗した項目の再キュー、完了項目の削除、キュー項目の右クリックメニュー（選択を中止・再キュー・チャットリプレイを取得・保存先を開く）があります。
- 停止ボタンでキュー全体を止められます。項目ごとの中止もできます。
- 常に最前面に表示するかどうかを切り替えられます。実行ログは画面下部に出ます。

### ライブ録画
- 「ライブ」を付けて追加すると、すぐに録画を始めます。「配信開始から録画」も選べます。
- 録画が終わったら（停止・中止で止めた場合も）、途中のファイルから完成した録画ファイルを作ります。映像と音声が分かれていれば、再エンコードせずに結合し、サムネイルを埋め込みます。

### チャットリプレイの取得
- 「チャットリプレイ取得」を付けると、動画とは別のJSONファイルとして、チャットリプレイを取得します。動画の取得が成功していれば、チャットの取得に失敗してもステータスは「ダウンロード完了」のままです（警告は実行ログに出ます）。
- YouTube：ライブ以外は、動画の取得中、後処理（マージ・移動）に入った時点でチャット取得を並行して始めます。ライブ録画は、録画の後にアーカイブから取ります。まだ取れていないライブ録画の項目は、「チャット未取得」と表示され、右クリックから後で取り直せます。
- Twitch：TwitchDownloaderCLI（設定でパスを指定）で、動画取得の後にチャットを取ります。

### 絵文字キャッシュの事前投入
チャットリプレイに含まれる絵文字・エモートの画像を、`emoji_cache.sqlite`（vlc-chatと共有）に入れます。

- キュー項目：チャット取得の後に、自動で投入します。
- チャンネル事前投入：登録したチャンネルの最近のアーカイブ（N件）について、動画は取らずにチャットリプレイだけを取り、投入します。処理済みのアーカイブは次回から飛ばします。
- フォルダ一括投入：指定したフォルダにある既存のチャットリプレイを、まとめて投入します。
- 「絵文字キャッシュ ▼」から開始と中止ができます。キューの停止では止まりません。

### 長い動画を速くする設定
- 一時フォルダ：途中のファイルを別のフォルダに置き、完成物だけを出力先へ移します（ライブ録画には適用しません）。
- 断片の並列取得（並列数）、ダウンロード中の `.part` を使わない設定、リトライ回数と間隔。

### 外部ツールの自動更新
アプリの起動時に、次のツールを確かめ、新しい版があれば自動で更新します。設定は無く、常に行います。

- yt-dlp（`yt-dlp -U`）
- ffmpeg（ffmpeg・ffprobe・ffplay）：[BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds) の release 追従の static ビルド。ハッシュを検証してから入れ替え、旧版は `.old` で1世代残します。
- deno：PATH の先頭にあるもの（`deno upgrade`）
- TwitchDownloaderCLI

更新に失敗しても、実行ログへの警告だけでアプリは使えます。更新の間にキュー処理を始めると、更新が終わってから始まります。初回の起動では、ffmpeg が約190MBの static ビルドに置き換わります。詳しくは [docs/adr/0009](docs/adr/0009-auto-update-tools-ffmpeg-release-static.md) を参照してください。

## 設定とデータ
- 設定・エラーログ・処理済みアーカイブの記録は、実行ファイルの隣の `data\` に保存します（書き込めないときだけ `%APPDATA%\YtGui\`）。
- 設定画面では、yt-dlp・ffmpeg・TwitchDownloaderCLIのパス、出力先、一時フォルダ、絵文字キャッシュの出力先、チャンネルURLと件数N、並列数、リトライを指定します。

## ビルド
```bash
dotnet build YtGui/YtGui.csproj
dotnet publish YtGui/YtGui.csproj -c Release -o publish/<フォルダ名>   # 単一ファイル（YtGui.exe）
```

## 既知の制限

### Cookieファイルの同時使用

yt-dlpは、`--cookies` で渡したファイルを、終了のたびに書き戻します。チャットリプレイを取得するキュー項目（ライブ以外のYouTube）では、動画取得とチャット取得の2つのyt-dlpが、同じCookieファイルを同時に使うことがあります。チャンネル事前投入をキュー処理と並行して動かしたときも同じです。

ほぼ同時に終わった場合、片方が書き戻したCookieの更新を、もう片方が上書きして失う可能性があります。ファイルが壊れる可能性もゼロとは言えません（推測。実機では再現しておらず、Cookieファイルが壊れたことはありません）。失われた更新は、次の実行で取り直されるのが普通です。

ログインが必要な動画で認証エラーが続くときは、Cookieファイルを書き出し直してください。詳しくは [docs/adr/0008](docs/adr/0008-chat-fetch-starts-during-postprocessing.md) を参照してください。
