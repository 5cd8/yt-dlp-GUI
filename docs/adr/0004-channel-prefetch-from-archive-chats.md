# チャンネル事前投入は、絵文字一覧ではなくアーカイブのチャットリプレイから絵文字を集める

チャンネル事前投入では、チャンネルが持つ絵文字・エモートの一覧を取得するのではなく、最近のアーカイブのチャットリプレイだけを取得し、キュー項目と同じ抽出処理で絵文字キャッシュ投入を行う。YouTubeはログインしていない状態では絵文字の一覧がどこにも無く（2026-10-02に配信中のチャットとメンバーシップ加入ページで確認）、一覧のURLとチャット本文に出るURL（`thumbnails[0].url`）が一字一句一致する保証も無い。アーカイブのチャットから集めれば、vlc-chatが検索するURLと必ず一致する。

## Considered Options

- Twitchの公式API（Helix）でチャンネルとグローバルのエモート一覧を取得する: dev.twitch.tv でのアプリ登録が要る。視聴者が他チャンネルのサブスクで使えるエモートを拾えず、実際のチャットでの取りこぼしが大きいため却下。
- Twitchの非公式GQL: 予告なく使えなくなるおそれがあるため却下。
- cookieでログインしたYouTubeの絵文字一覧: 一覧が取れるかも、URLが一致するかも未確認のため却下。

## Consequences

- まだチャットで使われていない新しい絵文字はキャッシュされない。
- アーカイブ1本ごとにチャットリプレイを取得するので時間がかかる。そのため、処理済みのアーカイブを記録して2回目以降は飛ばす。
