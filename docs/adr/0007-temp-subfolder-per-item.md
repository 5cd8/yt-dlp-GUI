# 一時フォルダは項目ごとのサブフォルダに分け、成功したら空のサブフォルダを消す

一時フォルダを使うとき（ライブ録画を除く）は、`-P temp:<一時フォルダ>\<ハッシュ12桁>` を渡す。ハッシュは、`YtDlp.NormalizeUrl` を通したURL・`SelectedFormat`・`AudioOnly`・`Codec` を `\n` でつないだ文字列の SHA-256 の先頭6バイト（小文字16進12桁）。成功（exit 0）後にそのサブフォルダが空なら、再帰なしで消す。失敗・中止のものは、再開用に残す。

理由は、実機のyt-dlp 2026.08.19での再現（Issue #36）。`--no-part` の単一フォーマット（TwitchのHLSなど、断片のあるもの）を途中で止めると、一時フォルダに完成名のファイル（`Same.mp4`）と断片の進み具合の記録（`Same.mp4.ytdl`）が残る。出力先には何も無いので、同じタイトルの別動画を取ると `MakeUniquePath` が同じ名前を選び、yt-dlpは残った途中ファイルの続きとして取る。完成物は、冒頭が古い動画で残りが新しい動画になり、警告も出ず終了コードも0なので、アプリもyt-dlpも気付けない。同じURLを別のフォーマットで取り直した場合も同じように混ざる。項目ごとのサブフォルダに分けると、どちらも混ざらず、同じURL・同じフォーマットの再実行は続きから再開できる。yt-dlpは成功後も空のサブフォルダを自分では消さないので、アプリが消す。

## Considered Options

- 案B、ファイル名に動画IDを付ける: 同名の別動画には効くが、同じURLの別フォーマットには効かない（IDが同じ）。出力ファイル名が変わり、保存済みのファイル・チャットJSON・vlc-chatの対応付けに影響するため却下。
- 案C、`MakeUniquePath` が一時フォルダも見る: 同じURLの再実行も別名になり、再開の価値が無くなるため却下。

## Consequences

- 同じURL・同じフォーマットの再実行は再開できる。別のURL・別フォーマットは別のサブフォルダなので混ざらない。
- 失敗・中止で残るサブフォルダは掃除しない（ADR 0006のとおり）。
- `Codec` は音声のみがオフでも入れる（Issueの確定要件）ので、動画でコーデックの値だけ変えた再実行は、別のサブフォルダになり再開できない。混ざらない方向の誤り。
- YouTube以外のURLは、`NormalizeUrl` が綴りを揃えないので、`www.` の有無・クエリ・`#` の違いで別のサブフォルダになり、再開できない。混ざらない方向の誤り。
- CookieやUseNoPartの切り替えでは分けない。取得物の内容を変えるのはURLとフォーマットで、切り替えても混ざらない。
- `SelectedFormat` が `bestaudio+bestvideo` のようなフォーマット指定の文字列のとき、同じ文字列でも、yt-dlpが実際に選ぶフォーマットは実行のたびに変わりうる（後から高画質版が出た場合など）。その場合も同じサブフォルダで再開しようとする。「同じURL・同じフォーマット」の範囲内として許容する。
- **ADR 0006の版（#34）で一時フォルダの直下に残った途中ファイルは、更新後は再開に使われず、自動でも消えない**。手で消す。
- 成功直後の削除は、ウイルス対策ソフトなどがフォルダのハンドルを持っていると、まれに失敗して空のサブフォルダが残る。失敗は無視する（ステータスは動画取得の成否だけで決める。ADR 0001）。残ったサブフォルダは、次回の同じ項目の実行が使う。
- アプリ外で一時フォルダに置かれたファイルは、サブフォルダが空でなければ消えない。
- `[MoveFiles]` の最中に中止すると、出力先に途中までのファイルが完成名で残る問題は別件（ADR 0006）。
