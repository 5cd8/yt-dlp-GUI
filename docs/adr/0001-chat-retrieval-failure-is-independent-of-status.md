# チャット取得の失敗はキュー項目のステータスに反映しない

チャットリプレイ機能の追加にあたり、チャット取得が失敗した場合にキュー項目を`失敗`扱いにするか検討した。動画取得さえ成功していればユーザーの主目的は達成されているため、チャット取得の失敗は実行ログへの警告出力のみとし、ステータスは動画取得の成否だけで決める（`失敗`にしない）ことにした。チャットリプレイは付加情報であり、それが理由で動画本体のダウンロード成功が失敗扱いになるのは体験として過剰、という判断。

## Considered Options

- キュー項目全体を`失敗`にする: 動画は手元にあるのにユーザーが「失敗した」と誤解し、`失敗を再キュー`で動画ごと再ダウンロードしてしまう恐れがあるため却下。
