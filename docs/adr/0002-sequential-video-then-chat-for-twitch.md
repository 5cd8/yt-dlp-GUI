# Twitchは動画取得→チャット取得を逐次実行する

Twitchのキュー項目はyt-dlp（動画）と外部ツール（チャット）という2つの別プロセスを要する。既存のキュー処理ループは「1キュー項目＝1プロセスを起動して完了を待つ」という前提で進捗表示・完了判定・中止処理が組まれているため、この前提を壊さずに済む逐次実行（動画完了後にチャット取得を開始）を選んだ。

## Considered Options

- 並行実行: 合計時間は短縮できるが、進捗表示・完了判定・中止処理を「1項目に対して複数プロセス」を前提に作り直す必要があり、実装コストと不具合リスクが見合わないと判断し却下。チャットは動画より短時間で終わるため、逐次実行による体感の待ち時間増加も限定的。
